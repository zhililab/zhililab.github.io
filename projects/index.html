Build 03

Kubernetes 生产现场

2026-08-06 部署已验证 · Azure East Asia

Kubernetes · 发布治理 · 可观测性 · Runbook

动机
把 Kubernetes 知识从组件记忆，转成能在生产场景中提出判断、收集证据并执行可逆处置的能力。
方法
围绕调度、网络、存储、发布与安全建立学习路径；用故障图谱、发布门禁、架构决策和证据链串起现场动作。
结果
学习站提供可展开的故障演练、发布控制步骤、决策卡片、证据链与本机进度保存的实战清单。
工程主线
从生产知识整理，到故障场景训练，再到可运行的平台工程。
能力表达
Walker 的 Kubernetes 生产工程实践：以证据链完成架构设计、部署验证、故障诊断与可逆运维。
最新工程落地
在学习站基础上，完成 Jenkins Controller + Kubernetes 动态 Pod Agent 的云端部署；Pipeline 验证确认动态 Pod Agent 已创建、执行并回收。
当前边界
页面中的集群状态、故障对象和指标用于学习演练，不代表实时生产集群数据或操作指令。以上是 2026-08-06 的一次部署验证，不是实时监控、持续在线或 SLA 承诺；为节省云额度，Jenkins 可能暂停运行。
